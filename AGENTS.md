# Collaboration Index

Canonical Inspect and task QA skills apply. One team attempt is one Inspect
sample; peers are not independent observations. Keep task definitions, trusted
submission state and scoring separate from the selectable agent.

Use the versioned board API and journal for agent communication. Do not expose
credentials, answer keys, private hands belonging to other agents, or operator
artifacts through tools. Participant IDs are evaluator-controlled; names are
agent-chosen. Keep logs/ flat and .eval-only; supporting files belong under
run-artifacts/. Tests delete only their own mock logs.

This repository currently provides local prototypes and mock verification.
Creating a configuration does not authorize paid runs, remote publication or
deployment. Preserve source repositories and active boards. Read docs/design.md
before changing the measurement contract. All authored functions need concise
summary docstrings.
