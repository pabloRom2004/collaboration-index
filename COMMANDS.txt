COMMANDS FOR COLLABORATION INDEX ON HAWK

Purpose: run the InferenceBench collaboration task on the Generality Labs Hawk
service from the MPI-IS login node. Hawk runs the Inspect controller. The task
creates its own RunPod H100 pods. No HTCondor job and no cluster GPU is used.

Requirements:
- hawk CLI 2.2.0 (`uv tool install "hawk[cli]==2.2.0"`) with the local proxy
  patch `_hawk_proxy_patch.pth` in its site-packages (aiohttp must use
  $https_proxy on this cluster).
- `hawk login` done once. The browser callback goes to localhost:18922 on the
  login node; deliver it with `curl --noproxy '*' "<callback URL>"`.
- ~/.config/collaboration-index/hawk.secrets (mode 600) with
  OPENROUTER_API_KEY and RUNPOD_API_KEY.
- Eval-set configs live under run-artifacts/<run>/ (gitignored). Pin the
  task package to a full commit SHA that is pushed to GitHub.

Submit one eval set:

  hawk eval-set run run-artifacts/<run>/<config>.yaml \
    --secrets-file ~/.config/collaboration-index/hawk.secrets

Watch the job and guard its RunPod pods (deletes inferencebench-* pods older
than the cap, or alive 15 minutes after the job stops):

  hawk watch <job-id> --no-follow
  set -a; . ~/.config/collaboration-index/hawk.secrets; set +a
  python3 -I run-artifacts/hawk-smoke-20261028/watchdog.py <job-id> --max-pod-hours 3

List RunPod pods directly:

  curl -sS -H "Authorization: Bearer $RUNPOD_API_KEY" https://rest.runpod.io/v1/pods

Download logs after the run:

  hawk download <job-id>
